Privacy Policy

Jarvis personal assistant · effective 11 October 2026

Who uses Jarvis

Jarvis is a personal assistant used by a single person, its owner, on their own computer. It is not available to the public. The only Google account it ever connects to is the owner's own.

Google data Jarvis accesses

  • Google Calendar events (calendar.events): to tell the owner what is planned and to add or move events at the owner's request.
  • Gmail, read-only (gmail.readonly): to list, search and read the owner's email when the owner asks about it.
  • Gmail drafts (gmail.compose): to create draft replies. Jarvis never sends email and never deletes email or events.

How the data is handled

  • Data is fetched only when the owner asks a question that needs it, and is used only to answer that question.
  • The Google sign-in token is stored in a file on the owner's computer that only the owner's Windows account can read. It is never put in the browser, in backups or in any public place.
  • To produce an answer, the relevant parts of calendar events or emails are sent to the Anthropic Claude API, the language model that powers Jarvis. Data sent through the API is handled under Anthropic's commercial terms and is not used to train models.
  • Google data is not sold, not shared with anyone else, not used for advertising and not used to train any AI model.
  • Jarvis does not keep its own copy of the owner's email or calendar.

Google API Services User Data Policy

Jarvis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Jarvis then loses access immediately.
